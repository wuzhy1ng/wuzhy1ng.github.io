What UniTracer does

从模糊线索到清晰证据，
在同一个工作台完成

每个功能都围绕实际调查过程设计：先理解案件材料，再自动追踪资金路径，最后沉淀为可检查、可解释、可分享的调查结果。

01 / INTAKE
AI

AI 协助立案

上传 PDF、Excel、CSV 等案件材料。Agent 通过对话梳理诉求、识别地址与链，自动生成可编辑的追踪计划。

02 / TRACE
TX

多链资金追踪

从一个或多个地址出发，结合链上交易数据与 Node Agent 判断，持续扩展值得调查的下一跳。

03 / GRAPH
G

可交互关系图

以 ForceAtlas2、层级、环形、时间线等布局观察资金网络，支持缩放、平移、节点拖拽与条件过滤。

04 / EVIDENCE
DB

交易证据下钻

点击任意地址即可查看标签、决策来源与完整转账表，支持资产筛选、排序、分页及哈希复制。

05 / ASSISTANT
Q

AI 案件问答助手

系统动态与用户问答汇入同一时间线。助手复用案件上下文，帮助解释路径、比较节点并归纳阶段发现。

06 / SHARE
↗

静态案件导出

把图谱、重放、报告、活动记录和转账数据导出为单个 HTML 文件，方便在离线主机上安全分享。
